# Kismet NetXML to KML Converter (Python 3)

This repository provides a modernized version of the `kurankat / kis2kml` tool, specifically refactored to support **Python 3**. It is designed to parse Kismet `.netxml` files and export geolocated network data to `.kml` files for visualization in Google Earth or other GIS platforms.

## Credits & Acknowledgments

This repository is a Python 3 fork of **kurankat/kis2kml**. It refactors the original **kis2kml.py** to be exclusively compatible with Python 3. For further details, see the original repository: https://github.com/kurankat/kis2kml
